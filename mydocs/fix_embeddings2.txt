Problem 1: Wrong API — You're hitting Lens.org or EPO, not PatentsView
FI20246315A1, FR3168305A1 are Finnish and French patent numbers in international format. PatentsView only contains USPTO patents with numeric IDs like 10000000. Your search is routing to a different API entirely, or your PatentsView query is returning zero results and something is falling back to an international patent source.
Check your config.py and search_service.py — confirm the URL is strictly https://search.patentsview.org/api/v1/patent/ and nothing else is being called.
Problem 2: No abstracts = BM25 scores are all zero
Every patent shows bm25 = 0 in your ranking. Your build_patent_text() function is receiving records with no patent_abstract field, so BM25 has nothing to tokenize. The cosine scores are also suspiciously uniform (all 0.45x) — that's the embedding model comparing your query against title-only text like "FR 3168305 (A1)", which is meaningless.
Problem 3: The title field contains the publication number, not a real title
"FR 3168305 (A1)" is not a patent title — it's the publication number repeated. These records have no usable text content at all. Your PatentRecord schema is mapping the wrong API response fields.

def _validate_patent_record(raw: dict) -> bool:
    """
    Reject records that have no usable text content.
    These will produce meaningless embeddings and waste compute.
    """
    patent_id = raw.get("patent_id", "")
    title = raw.get("patent_title", "")
    abstract = raw.get("patent_abstract", "")

    # Reject non-USPTO patent IDs (should be numeric)
    if not patent_id.replace("-", "").isdigit():
        log.warning(f"Non-USPTO patent_id rejected: {patent_id}")
        return False

    # Reject records where title = publication number (no real content)
    if title == patent_id or title.startswith(patent_id[:4]):
        log.warning(f"Title looks like publication number, rejected: {title}")
        return False

    # Reject records with no searchable text
    if not title and not abstract:
        log.warning(f"No text content in record: {patent_id}")
        return False

    return True

Even after fixing the source, add defensive guards in both retrieval components so future bad records don't silently corrupt scores:
python# services/embedding_service.py

def build_patent_text(patent: PatentRecord) -> str:
    title = (patent.patent_title or "").strip()
    abstract = (patent.patent_abstract or "").strip()

    # Guard: if both are empty, flag it — don't embed garbage
    if not title and not abstract:
        log.warning(f"Patent {patent.patent_id} has no text — embedding will be noise")
        return f"patent {patent.patent_id}"  # minimal placeholder

    if not abstract:
        log.debug(f"Patent {patent.patent_id} has no abstract — title only")
        return f"{title}. {title}"  # double title as fallback weight

    return f"{title}. {title}. {abstract}"


# retrieval/bm25_ranker.py

def build_index(patents: list[PatentRecord]) -> BM25Okapi:
    corpus = []
    for p in patents:
        text = f"{p.patent_title or ''} {p.patent_abstract or ''}".strip()
        if not text:
            text = f"patent {p.patent_id}"  # prevent empty token list crash
        corpus.append(text.lower().split())
    return BM25Okapi(corpus)
