1.3 search_service.py Code Review
Your working demo is solid. Three specific improvements to carry forward into the production version:

Issue 1 — .env parsing: You are manually parsing .env. Use python-dotenv instead. Call load_dotenv() at app startup in config.py and never parse .env files in individual services.

Issue 2 — Hardcoded fields list: The 'f' array ['patent_id','patent_title','patent_abstract','patent_type'] should live in config.py as PATENT_FIELDS so all services agree on the schema.

Issue 3 — No pagination: PatentsView returns max 1000 results per page. Add an 'o' offset parameter and loop until results < page_size to ensure full recall.

Step 5: Deduplication Service
After search, deduplicate on patent_id. This is essential because query expansion will generate multiple queries that return overlapping results.

# services/dedup_service.py
def deduplicate(patents: list[PatentRecord]) -> list[PatentRecord]:
    seen = {}
    for p in patents:
        if p.patent_id not in seen:
            seen[p.patent_id] = p
    return list(seen.values())

# models/mistral_client.py
import ollama
class MistralClient:
    def __init__(self, model: str = 'mistral'):
        self.model = model
    def generate(self, prompt: str) -> str:
        response = ollama.generate(model=self.model, prompt=prompt)
        return response['response'].strip()

Step 8: Embedding Model
Use sentence-transformers to load BGE-large-en-v1.5 locally. Wrap it to always return normalized numpy arrays. Add a batch method for efficiency — embedding one patent at a time is 10x slower than batching.

# models/embedding_model.py
from sentence_transformers import SentenceTransformer
import numpy as np
class EmbeddingModel:
    def __init__(self, model_name: str = 'BAAI/bge-large-en-v1.5'):
        self.model = SentenceTransformer(model_name)
    def embed(self, texts: list[str]) -> np.ndarray:
        return self.model.encode(texts, normalize_embeddings=True, batch_size=32)

Step 9: Claude Client
Wrap the Anthropic SDK. Expose two methods: compare() and generate_report(). Store max_tokens and model in config.

# models/claude_client.py
import anthropic
class ClaudeClient:
    def __init__(self):
        self.client = anthropic.Anthropic()
        self.model = 'claude-3-5-sonnet-20241022'
    def complete(self, system: str, user: str, max_tokens: int = 4096) -> str:
        msg = self.client.messages.create(
            model=self.model, max_tokens=max_tokens,
            system=system,
            messages=[{'role': 'user', 'content': user}]
        )
        return msg.content[0].text


Phase 4 — Services (Days 7–10)

Step 10: Query Expansion Service
Load your prompt from prompts/query_expansion.txt. The prompt should instruct Mistral to return a JSON array of alternative search terms. Parse the response and fall back to the original query on failure.

# services/query_expansion.py
import json
PROMPT_TEMPLATE = open('prompts/query_expansion.txt').read()

def expand_query(query: str, client: MistralClient) -> list[str]:
    prompt = PROMPT_TEMPLATE.format(query=query)
    raw = client.generate(prompt)
    try:
        terms = json.loads(raw)
        return [query] + [t for t in terms if isinstance(t, str)]
    except json.JSONDecodeError:
        logger.warning('Query expansion parse failed, using original')
        return [query]

prompts/query_expansion.txt should read something like:

You are a patent search expert. Given the search query below, generate 5 alternative technical search terms that would help find related patents. Consider synonyms, broader/narrower concepts, and different technical formulations. Return ONLY a JSON array of strings, no explanation.  Query: {query}

Step 11: Embedding & Retrieval Services
embedding_service.py takes a list of PatentRecords, concatenates title + abstract for each, and stores embeddings in the vector store. similarity.py computes cosine similarity between the query embedding and all patent embeddings as a vectorized numpy operation — do not loop.

# retrieval/similarity.py
import numpy as np
def cosine_similarity_matrix(query_vec: np.ndarray, doc_vecs: np.ndarray) -> np.ndarray:
    # Both inputs must already be L2-normalized
    return doc_vecs @ query_vec  # shape: (n_docs,)

Step 12: BM25 Ranker
Use the rank-bm25 library. Build the index from patent text at search time (or cache it). BM25 operates on tokenized text — use a simple whitespace tokenizer initially, upgrade to a patent-specific tokenizer later.

# retrieval/bm25_ranker.py
from rank_bm25 import BM25Okapi
def build_index(patents: list[PatentRecord]) -> BM25Okapi:
    corpus = [(p.patent_title + ' ' + (p.patent_abstract or '')).split()
              for p in patents]
    return BM25Okapi(corpus)

def get_scores(index: BM25Okapi, query: str) -> list[float]:
    return index.get_scores(query.split())

Step 13: Hybrid Ranking Service
Normalize both score arrays to [0,1] using min-max normalization before combining. Raw BM25 scores and cosine scores are on different scales — combining without normalization will make one dominate.

# services/ranking_service.py
import numpy as np
from app.config import settings

def normalize(scores: np.ndarray) -> np.ndarray:
    mn, mx = scores.min(), scores.max()
    return (scores - mn) / (mx - mn + 1e-9)

def hybrid_rank(cosine: np.ndarray, bm25: np.ndarray) -> np.ndarray:
    c = normalize(cosine)
    b = normalize(bm25)
    return settings.cosine_weight * c + settings.bm25_weight * b
