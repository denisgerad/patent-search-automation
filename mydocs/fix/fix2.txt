def normalize_bm25(scores):
    min_s = min(scores)
    max_s = max(scores)

    if max_s == min_s:
        return [0.0 for _ in scores]

    return [(s - min_s) / (max_s - min_s) for s in scores]

Now BM25 is in [0,1].

🎯 PART 2 — Cosine Threshold Logic (Clean & Defensible)
This is critical.
Without thresholding, irrelevant documents slip in.

Recommended Threshold Strategy (PoC Level)
Step 1 — Hard Floor

Discard obviously weak matches:
if cosine < 0.40:
    discard

Why 0.40?

Empirical observation:
<0.30 → unrelated
0.30–0.40 → weak
0.50 → meaningful
0.65 → strong
0.40 is a safe initial filter.

Step 2 — Adaptive Threshold (Optional Advanced)
If you want smarter filtering:
mean_cos = np.mean(cosines)
std_cos = np.std(cosines)

threshold = mean_cos - 0.5 * std_cos

But for PoC:
👉 Use fixed threshold.

Step 3 — Minimum Candidate Guarantee
If after filtering you get <5 results:
Lower threshold gradually to 0.35.
Never drop below 0.30.
